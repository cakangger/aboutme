# 🚀 Angger's Personal Portfolio & Web Page

Welcome to the official source repository for my personal portfolio web page.

🌐 **Live Demo**: [https://cakangger.github.io/aboutme/](https://cakangger.github.io/aboutme/)

---

## ✨ Key Features

- **Dark Glassmorphic UI**: Sleek futuristic aesthetic with neon accents and ambient backdrop blurs.
- **Interactive Canvas Particles**: HTML5 canvas rendering reactive node connections.
- **Live Theme Customizer**: Real-time switching between 4 themes (*Cyber Neon*, *Aurora Borealis*, *Midnight OLED*, *Matrix Hacker*).
- **Typewriter Effect**: Dynamic hero headlines and role animations.
- **Skills & Projects Matrix**: Filterable showcase with quick-view modal popups.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Built With

- **HTML5**: Semantic web architecture & meta tags.
- **CSS3**: Custom CSS variables, keyframe animations, glassmorphism, responsive grids.
- **JavaScript (ES6+)**: Canvas animations, theme manager, project filter logic, modal drawer.
- **FontAwesome & Google Fonts**: Modern iconography and typography.
